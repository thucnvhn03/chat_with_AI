# UT-001 — Trích xuất PDF giữ số trang

Nhóm: [01 — Ca kiểm thử đơn vị (UT-001..UT-022)](README.md) · Kế hoạch: [Master_Test_Plan.md](../../Master_Test_Plan.md)

| Mục | Nội dung |
|---|---|
| Mục tiêu | Mô-đun trích xuất trả văn bản theo từng trang, số trang bắt đầu từ 1, đúng thứ tự |
| Truy vết | BR-019, AC-019, US-015, T1-13 |
| Ưu tiên / Loại | Cao / Dương |
| Điều kiện trước | Có phông Unicode (DejaVu) để sinh PDF |
| Dữ liệu | PDF 3 trang: "Trang mot noi dung A.", "Trang hai noi dung B.", "Trang ba C." |
| Tự động hóa | `backend/tests/unit/test_extract.py::test_plain_pdf_keeps_page_numbers` |

**Các bước**
1. Sinh PDF 3 trang bằng `pdf_factory.make_pdf`.
2. Gọi `extract_pages(data, MIN_TEXT_CHARS=20)`.

**Kết quả mong đợi**
- Trả về 3 phần tử, `page` lần lượt 1, 2, 3.
- Văn bản trang 2 chứa "noi dung B".
