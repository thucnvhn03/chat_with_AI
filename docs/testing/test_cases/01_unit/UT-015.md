# UT-015 — Adapter OIDC: kiểm tra ID token

Nhóm: [01 — Ca kiểm thử đơn vị (UT-001..UT-022)](README.md) · Kế hoạch: [Master_Test_Plan.md](../../Master_Test_Plan.md)

| Mục | Nội dung |
|---|---|
| Mục tiêu | URL ủy quyền dùng PKCE; đổi mã gửi `code_verifier`; ID token sai nonce, aud, iss hoặc hết hạn bị từ chối |
| Truy vết | BR-014, T1-03 |
| Ưu tiên / Loại | Cao / Dương, âm |
| Dữ liệu | IdP giả (`httpx.MockTransport`) với discovery và token endpoint; claims hợp lệ và 4 biến thể sai |
| Tự động hóa | `test_oidc_adapter.py::test_authorization_url_uses_pkce`, `test_exchange_returns_identity_and_sends_verifier`, `test_exchange_rejects_invalid_token` |

**Các bước**
1. Gọi `authorization_url("s1", "n1", "challenge")`.
2. Gọi `exchange_code("code-1", "verifier-1", "n1")` với claims hợp lệ.
3. Lặp lại với từng biến thể sai.

**Kết quả mong đợi**
- URL có `code_challenge=challenge`, `code_challenge_method=S256`, `state`, `nonce`.
- Claims hợp lệ → `subject = "user-123"`, email đúng; token endpoint nhận `code_verifier = verifier-1`.
- Mỗi biến thể sai → `OidcError`.
