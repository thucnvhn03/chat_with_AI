# UT-011 — Ghép câu hỏi trước vào truy vấn

Nhóm: [01 — Ca kiểm thử đơn vị (UT-001..UT-022)](README.md) · Kế hoạch: [Master_Test_Plan.md](../../Master_Test_Plan.md)

| Mục | Nội dung |
|---|---|
| Mục tiêu | Truy vấn truy xuất = câu hỏi người dùng ở lượt trước + câu hỏi hiện tại; không có lịch sử thì giữ nguyên |
| Truy vết | BR-008, AC-008, US-010, T3-05 |
| Ưu tiên / Loại | Trung bình / Dương |
| Dữ liệu | Lịch sử: user "Hợp đồng A có điều khoản phạt không?", assistant "Có."; câu mới "Mức phạt là bao nhiêu?" |
| Tự động hóa | `test_qa_service.py::test_retrieval_query_appends_previous_user_question` |

**Các bước**
1. Gọi `retrieval_query(câu mới, lịch sử)`.
2. Gọi `retrieval_query("Câu đầu", [])`.

**Kết quả mong đợi**
- Kết quả 1: "Hợp đồng A có điều khoản phạt không?\nMức phạt là bao nhiêu?".
- Kết quả 2: "Câu đầu".
