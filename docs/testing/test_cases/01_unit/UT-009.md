# UT-009 — Lớp từ chối 3: có nội dung nhưng không có nguồn hợp lệ

Nhóm: [01 — Ca kiểm thử đơn vị (UT-001..UT-022)](README.md) · Kế hoạch: [Master_Test_Plan.md](../../Master_Test_Plan.md)

| Mục | Nội dung |
|---|---|
| Mục tiêu | Câu trả lời có nội dung mà không có citation, hoặc citation trỏ ngoài danh sách chunk → `not_found` |
| Truy vết | BR-012, AC-012, US-014, ADR-011, T2-04 |
| Ưu tiên / Loại | Cao / Âm |
| Dữ liệu | Adapter chế độ `no_citations`; chế độ `bad_index` (chỉ số = số chunk + 5) |
| Tự động hóa | `test_qa_service.py::test_layer3_content_without_citation`, `test_layer3_citation_index_out_of_range_is_invalid`, `test_answer_with_content_always_has_citation` |

**Các bước**
1. Gọi `answer_question` với từng chế độ.
2. Lặp qua mọi chế độ của adapter, kiểm điều kiện bất biến.

**Kết quả mong đợi**
- `not_found = True`, `reason = "no_valid_citation"`.
- Bất biến: mọi kết quả hoặc `not_found`, hoặc có ≥ 1 citation.
