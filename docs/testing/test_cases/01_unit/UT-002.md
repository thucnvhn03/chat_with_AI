# UT-002 — Chuẩn hóa tiếng Việt về NFC

Nhóm: [01 — Ca kiểm thử đơn vị (UT-001..UT-022)](README.md) · Kế hoạch: [Master_Test_Plan.md](../../Master_Test_Plan.md)

| Mục | Nội dung |
|---|---|
| Mục tiêu | Văn bản tiếng Việt ở dạng tổ hợp (NFD) được chuẩn hóa về dạng dựng sẵn (NFC), không mất dấu |
| Truy vết | BR-010, AC-010, US-012, T1-13 |
| Ưu tiên / Loại | Cao / Dương |
| Dữ liệu | Câu "Hợp đồng phân phối có hiệu lực 24 tháng kể từ ngày ký." ở dạng NFD |
| Tự động hóa | `test_extract.py::test_vietnamese_text_is_nfc_and_keeps_diacritics` |

**Các bước**
1. Sinh PDF một trang từ câu ở dạng NFD.
2. Gọi `extract_pages`.

**Kết quả mong đợi**
- Văn bản trích xuất bằng chính nó sau `unicodedata.normalize("NFC")`.
- Chứa nguyên cụm "Hợp đồng phân phối" và "24 tháng".
