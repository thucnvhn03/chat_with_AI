# UT-003 — Phân loại lỗi PDF

Nhóm: [01 — Ca kiểm thử đơn vị (UT-001..UT-022)](README.md) · Kế hoạch: [Master_Test_Plan.md](../../Master_Test_Plan.md)

| Mục | Nội dung |
|---|---|
| Mục tiêu | PDF có mật khẩu, PDF hỏng, PDF chỉ có ảnh được phân loại đúng lý do |
| Truy vết | BR-018, AC-018, US-003, US-004, T1-13 |
| Ưu tiên / Loại | Cao / Âm |
| Dữ liệu | (a) PDF mã hóa AES-256 có mật khẩu mở; (b) tệp bắt đầu bằng `%PDF-` nhưng nội dung rác; (c) PDF 3 trang chỉ có hình vẽ |
| Tự động hóa | `test_extract.py::test_encrypted_pdf`, `test_corrupted_pdf`, `test_random_bytes_are_corrupted`, `test_image_only_pdf_has_no_text` |

**Các bước**
1. Với từng tệp, gọi `extract_pages`.

**Kết quả mong đợi**
- (a) ném `ExtractionError` với `reason = "encrypted"`.
- (b) ném `ExtractionError` với `reason = "corrupted"`.
- (c) ném `ExtractionError` với `reason = "no_text"` (tổng ký tự < `MIN_TEXT_CHARS`).
