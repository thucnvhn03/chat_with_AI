# UI-003 — Trạng thái của thành phần

Nhóm: [08 — Ca kiểm thử giao diện (UI-001..UI-008)](README.md) · Kế hoạch: [Master_Test_Plan.md](../../Master_Test_Plan.md)

| Mục | Nội dung |
|---|---|
| Mục tiêu | Mỗi thành phần có đủ trạng thái mặc định, vô hiệu, đang tải, lỗi, trống |
| Truy vết | UIUX_Blueprint C-00..C-20, T0-05 |
| Ưu tiên | Trung bình |
| Tự động hóa | Vitest: `components.test.tsx`, `documents.test.tsx`, `chat.test.tsx`, `sources.test.tsx`, `admin.test.tsx`, `reports.test.tsx` |

**Các bước**
1. Với từng thành phần, tái hiện các trạng thái:
   - StatusBadge: Sẵn sàng, Đang xử lý, Đang tải lên, Lỗi, Chưa tải xong, Đang hoạt động, Đã thu hồi.
   - QuestionInput: trống (vô hiệu), tài liệu đang xử lý (vô hiệu + giải thích), bình thường, đang chờ, quá dài.
   - Nút Gửi / Đăng nhập / Cấp quyền / Xóa vĩnh viễn: bình thường, đang gửi (vô hiệu, đổi chữ).
   - Danh sách: đang tải, lỗi kèm "Thử lại", trống.

**Kết quả mong đợi**
- Mỗi trạng thái hiển thị đúng chữ và kiểu; nút vô hiệu không nhận thao tác.
