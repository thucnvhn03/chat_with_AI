**Các bước**
1. Tải tệp (theo dõi thanh tiến độ); chờ xử lý (nhãn "Đang xử lý" và câu "Chưa dùng được để trả lời…"); gửi câu hỏi (chỉ báo ba chấm + "Đang xử lý câu hỏi…" + "Hủy"); mở S-03 (chữ "Đang tải trang…").

**Kết quả mong đợi**
- Mỗi trạng thái hiển thị ngay; với người bật "giảm chuyển động" (`prefers-reduced-motion`), ba chấm không nhấp nháy.
