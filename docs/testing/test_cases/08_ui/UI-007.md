# UI-007 — Thông báo

Nhóm: [08 — Ca kiểm thử giao diện (UI-001..UI-008)](README.md) · Kế hoạch: [Master_Test_Plan.md](../../Master_Test_Plan.md)

| Mục | Nội dung |
|---|---|
| Mục tiêu | Thông báo tại chỗ đúng loại và đúng vị trí |
| Truy vết | C-16 ErrorBanner |
| Ưu tiên | Thấp |
| Tự động hóa | `components.test.tsx`, `admin.test.tsx` |

**Các bước và kết quả mong đợi**
- Banner lỗi (đỏ, `role=alert`), cảnh báo (vàng: hết phiên, xác nhận thu hồi), thông tin (xanh, `role=note`/`status`: "Đã cấp vai trò…", "Đã thu hồi quyền…").
- Banner xác nhận thu hồi có hai nút "Hủy" và "Thu hồi", không thực hiện khi chưa xác nhận.
