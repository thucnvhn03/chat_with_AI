# OPS-001 — Health báo lỗi khi một thành phần dừng

Nhóm: [11 — Ca kiểm thử vận hành và sẵn sàng (OPS-001..OPS-005)](README.md) · Kế hoạch: [Master_Test_Plan.md](../../Master_Test_Plan.md)

| Mục | Nội dung |
|---|---|
| Mục tiêu | Dừng thật từng thành phần thì `/health/ready` báo lỗi đúng thành phần; khởi động lại thì trở về bình thường |
| Truy vết | BR-022, AC-022, US-021, T4-04 |
| Ưu tiên | Trung bình |
| Tự động hóa | Tích hợp: INT-API-036 (giả lập lỗi); ca này là kiểm thử thủ công trên hệ thống thật |

**Các bước**
1. `docker compose -f deploy/docker-compose.yml up -d`; `curl http://localhost:8000/health/ready` → 200.
2. `docker compose stop objectstore`; gọi lại.
3. `docker compose start objectstore`; chờ healthy; gọi lại.
4. `docker compose stop worker`; tải 1 PDF qua giao diện; chờ hơn `QUEUE_MAX_AGE_S` (đặt tạm `QUEUE_MAX_AGE_S=60` để rút ngắn); gọi lại.
5. `docker compose start worker`; chờ hết việc; gọi lại.

**Kết quả mong đợi**
- Bước 2: 503, `components.storage.ok = false`, các thành phần khác `true`; `/health/live` vẫn 200.
- Bước 3, 5: 200.
- Bước 4: 503, `components.queue = {"ok": false, "detail": "queue_backlog"}`.
- Phản hồi không chứa chi tiết kỹ thuật (tên máy, thông điệp ngoại lệ).
