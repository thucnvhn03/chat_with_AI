# API-009 — `POST /events/source-opened`

Nhóm: [09 — Ca kiểm thử API theo hợp đồng (API-001..API-015)](README.md) (xem kiểm tra hợp đồng chung) · Kế hoạch: [Master_Test_Plan.md](../../Master_Test_Plan.md)

| Mục | Nội dung |
|---|---|
| Vào | `{"document_id": uuid, "page": int ≥ 1}` — không nhận nội dung |
| Ra | 204; ghi đúng một `usage_events(kind="source_opened")` |
| Lỗi | 404 (tài liệu ngoài phạm vi hoặc không `ready`); 400 (`page` < 1) |
| Ca chi tiết | `test_qa_flow.py::test_source_opened_event`; SEC-003 bước 5 |

**Các bước**
1. Gửi với tài liệu của mình, trang 2 → 204; đếm sự kiện = 1.
2. Người khác gửi cùng thân → 404; số sự kiện vẫn = 1.
