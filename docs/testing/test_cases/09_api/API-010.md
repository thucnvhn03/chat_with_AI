# API-010 — `POST /conversations`, `POST|GET /conversations/{id}/messages`

Nhóm: [09 — Ca kiểm thử API theo hợp đồng (API-001..API-015)](README.md) (xem kiểm tra hợp đồng chung) · Kế hoạch: [Master_Test_Plan.md](../../Master_Test_Plan.md)

| Mục | Nội dung |
|---|---|
| Vào | Tạo: không thân. Hỏi: `{"question": string}` |
| Ra | Tạo 201 `{"id"}`. Hỏi 200 `{"message_id", "answer", "not_found": bool, "citations": [{"document_id", "document_name", "page", "cited_text"}], "latency_ms"}`. Lịch sử 200: mảng `{"id", "role", "content", "not_found", "latency_ms", "created_at", "citations", "feedback"}` theo thứ tự thời gian |
| Lỗi | 400 `question_empty`, `question_too_long`; 404 `conversation_not_found` (của người khác); 502 `answer_unavailable`; 504 `answer_timeout` |
| Bất biến | `not_found = false` ⇒ `citations` không rỗng; `not_found = true` ⇒ `citations` rỗng |
| Ca chi tiết | INT-API-019..025 |
