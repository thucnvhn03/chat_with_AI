# E2E-005 — Tải PDF hợp lệ tới "Sẵn sàng"

Nhóm: [03 — Ca kiểm thử hệ thống / đầu-cuối (E2E-001..E2E-013)](README.md) · Kế hoạch: [Master_Test_Plan.md](../../Master_Test_Plan.md)

| Mục | Nội dung |
|---|---|
| Mục tiêu | Tệp xuất hiện với "Đang xử lý" rồi "Sẵn sàng", số trang đúng, ô hỏi mở |
| Truy vết | BR-001, AC-001, US-001, T1-21 |
| Ưu tiên | Cao |
| Dữ liệu | `HopDong_<ngẫu nhiên>.pdf`, 2 trang ASCII |
| Tự động hóa | `documents.spec.ts`: "tải PDF hợp lệ" |

**Các bước**
1. Đăng nhập `e2e.bd`.
2. Chọn tệp qua ô `file-input`.
3. Chờ tối đa 30 giây.

**Kết quả mong đợi**
- Tệp xuất hiện trong "Danh sách tài liệu"; nhãn "Sẵn sàng"; meta "2 trang".
- Ô "Câu hỏi của bạn" được bật; không vi phạm axe.
