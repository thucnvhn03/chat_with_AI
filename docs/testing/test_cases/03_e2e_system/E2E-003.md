# E2E-003 — Hết phiên giữ câu hỏi đang soạn

Nhóm: [03 — Ca kiểm thử hệ thống / đầu-cuối (E2E-001..E2E-013)](README.md) · Kế hoạch: [Master_Test_Plan.md](../../Master_Test_Plan.md)

| Mục | Nội dung |
|---|---|
| Mục tiêu | Khi phiên không còn hợp lệ, yêu cầu kế tiếp đưa về S-01 với thông báo hết phiên; câu hỏi đang soạn vẫn được giữ trong sessionStorage |
| Truy vết | US-017, PRD 4.2, T1-06 |
| Ưu tiên | Cao |
| Tự động hóa | `auth.spec.ts`: "hết phiên"; Vitest `LoginPage.test.tsx` (401 giữa phiên) |

**Các bước**
1. Đăng nhập `e2e.bd`.
2. Thay giá trị cookie `cwd_session` bằng "phien-het-han".
3. Nhập "Câu hỏi đang soạn dở" và nhấn "Gửi" (hoặc tải lại trang nếu ô nhập đang vô hiệu).

**Kết quả mong đợi**
- Về trang "Đăng nhập" với thông báo "Phiên làm việc đã hết hạn."
- (Vitest) `sessionStorage["cwd.draft"]` = câu hỏi đang soạn.
