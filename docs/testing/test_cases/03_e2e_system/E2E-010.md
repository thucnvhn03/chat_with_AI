# E2E-010 — Xóa tài liệu

Nhóm: [03 — Ca kiểm thử hệ thống / đầu-cuối (E2E-001..E2E-013)](README.md) · Kế hoạch: [Master_Test_Plan.md](../../Master_Test_Plan.md)

| Mục | Nội dung |
|---|---|
| Mục tiêu | Hộp thoại xác nhận (tiêu điểm ở "Hủy", Esc đóng và trả tiêu điểm); xóa xong tài liệu biến khỏi danh sách; câu hỏi chỉ có đáp án trong tài liệu đó nhận "không tìm thấy" |
| Truy vết | BR-005, AC-005, US-006, T3-08 |
| Ưu tiên | Cao |
| Dữ liệu | Tệp `XoaDi_<ngẫu nhiên>.pdf` chứa 3 từ ngẫu nhiên và mã `BIMAT_<ngẫu nhiên>` |
| Tự động hóa | `delete-audit.spec.ts`: "xóa tài liệu" |

**Các bước**
1. Đăng nhập `e2e.bd`; tải tệp; chờ "Sẵn sàng"; hỏi "<3 từ> la gi?" → câu trả lời chứa mã.
2. Nhấn "Xóa <tên>"; nhấn Esc.
3. Nhấn "Xóa <tên>"; nhấn "Xóa vĩnh viễn".
4. Nhấn "Hội thoại mới"; hỏi lại câu ở bước 1.

**Kết quả mong đợi**
- Bước 2: hộp thoại "Xóa tài liệu "<tên>"?", tiêu điểm ở "Hủy"; sau Esc hộp thoại đóng, tiêu điểm về nút "Xóa <tên>".
- Bước 3: tệp biến khỏi danh sách.
- Bước 4: "Không tìm thấy thông tin này…".
