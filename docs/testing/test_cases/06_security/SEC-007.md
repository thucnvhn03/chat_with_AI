# SEC-007 — Chống XSS từ nội dung câu trả lời

Nhóm: [06 — Ca kiểm thử bảo mật (SEC-001..SEC-013)](README.md) · Kế hoạch: [Master_Test_Plan.md](../../Master_Test_Plan.md)

| Mục | Nội dung |
|---|---|
| Mục tiêu | Nội dung từ mô hình hiển thị dưới dạng văn bản đã thoát ký tự, không thực thi |
| Truy vết | T2-08 |
| Ưu tiên | Cao |
| Dữ liệu | `<script>window.__xss = 1</script><img src=x onerror="window.__xss=2">` |
| Tự động hóa | Vitest `chat.test.tsx`: "nội dung có <script> hiển thị nguyên văn" |

**Các bước**
1. API trả câu trả lời chứa chuỗi trên; hiển thị thẻ câu trả lời.

**Kết quả mong đợi**
- Văn bản hiển thị nguyên chuỗi; DOM không có phần tử `script` hay `img` trong thẻ; `window.__xss` không được đặt.
- Tên tệp do người dùng đặt (chứa `<b>`) cũng hiển thị dạng văn bản (kiểm thủ công).
