# SEC-002 — Phân quyền theo vai trò

Nhóm: [06 — Ca kiểm thử bảo mật (SEC-001..SEC-013)](README.md) · Kế hoạch: [Master_Test_Plan.md](../../Master_Test_Plan.md)

| Mục | Nội dung |
|---|---|
| Mục tiêu | Mọi route `/admin/*` trả 403 với `bd` và `manager`; `/reports/*` từ chối `bd`; sự kiện `access_denied` được ghi |
| Truy vết | BR-014, US-017, T1-08 |
| Ưu tiên | Cao |
| Tự động hóa | `test_auth_matrix.py::test_admin_routes_forbidden_for_non_admin` (bd, manager); `test_auth.py::test_wrong_role_is_forbidden_role_and_records_access_denied`; `test_admin_reports_health.py::test_usage_endpoint_includes_helpful_ratio` |

**Các bước**
1. Đăng nhập lần lượt `bd` và `manager`; gọi mọi route `/admin/*`.
2. `bd` gọi `GET /admin/access`; đếm `usage_events` loại `access_denied`.
3. `bd` gọi `GET /reports/usage`.

**Kết quả mong đợi**
- Bước 1: mọi yêu cầu 403.
- Bước 2: 403 `forbidden_role`; đúng 1 sự kiện `access_denied`.
- Bước 3: 403.
